# Gestion de Magasin

Gestion de Magasin aide à gérer un petit commerce au quotidien. Le vendeur enregistre les ventes en quelques clics : il choisit un client, ajoute les produits au panier, choisit le mode de paiement (espèces ou Mobile Money) et imprime le reçu. Le stock diminue tout seul après chaque vente.

L’administrateur gère les produits, les catégories, les fournisseurs, les clients et les comptes des utilisateurs. Il reçoit aussi les marchandises dans la page Stock.

Le tableau de bord affiche d’un coup d’œil le nombre de ventes, le chiffre d’affaires, les produits les plus vendus et les produits qui doivent être recommandés.
